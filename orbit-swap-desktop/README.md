# Orbit Swap 데스크톱

Rust와 GPUI로 만든 macOS용 토큰 교환 연습 앱입니다. 가상의 토큰으로 교환을 연습하므로 지갑이나 인터넷 없이 실행할 수 있습니다.

## 처음 실행하기

Rust와 macOS Command Line Tools가 설치된 Mac에서 터미널로 이 폴더를 열고 `sh build-app.sh`를 실행하세요. 처음 빌드할 때 필요한 구성요소를 내려받습니다.

Finder에서 이 폴더에 생성된 `Orbit Swap.app`을 더블클릭하세요.

## 사용 방법

1. 보내는 수량에 `1`을 입력하면 받을 토큰의 예상 수량이 바로 표시됩니다.
2. 파란색으로 밑줄 친 **슬리피지 한도**나 **교환용 풀**을 눌러 뜻과 실제 사례를 읽어 보세요.
3. **교환 내용 확인**에서 내용을 읽고 **연습 교환 실행**을 누르면 잔액과 교환용 풀의 수량이 바뀝니다.
4. **방향 바꾸기**로 반대 방향을 연습하거나 **처음부터**로 초기 수량을 복원할 수 있습니다.

각 토큰의 초기 잔액은 100개, 풀에는 1,000개씩 들어 있습니다. 앱을 닫으면 연습 기록이 초기화됩니다.
